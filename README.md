# SyntaxWear - Tênis e Sneakers Online 👟

A **SyntaxWear** é uma landing page de um e-commerce moderno e responsivo focado na venda de calçados exclusivos. O projeto foi desenvolvido como parte de um estudo de desenvolvimento web, focando em estruturação semântica, estilização componentizada e design focado na experiência do usuário (UX).

---

## 🚀 Tecnologias Utilizadas

O projeto foi construído utilizando tecnologias fundamentais da web:

- **HTML5:** Estruturação semântica de toda a página.
- **CSS3:** Estilização avançada com o uso de:
  - **Variáveis CSS:** Para facilitar a manutenção de cores e fontes.
  - **Flexbox e CSS Grid:** Para criação de layouts responsivos e complexos.
  - **Arquitetura Componentizada:** Organização do CSS em pastas separadas por componentes (`header`, `hero`, `footer`, etc.).

---

## ✨ Funcionalidades

- **Design Responsivo:** Adaptado para dispositivos móveis (com menu hambúrguer) e desktops.
- **Banner Hero Impactante:** Seção de destaque com chamadas para ação (CTA).
- **Categorias de Produtos:** Navegação visual intuitiva entre os estilos Casual, Esporte, Moderno e Futurista.
- **Grid de Destaques:** Exibição dinâmica de produtos e modelos em um layout de grade moderno.
- **Newsletter e Redes Sociais:** Rodapé completo com formulário de inscrição e links sociais.

## 📂 Estrutura do Projeto

Abaixo está uma visão geral da organização dos arquivos:

```
ecommerce-syntaxwear/
├── css/
│   ├── components/            # CSS específico por seção

│   │   ├── product-category.css
│   │   └── product-grid.css

│   └── layout.css             # Estrutura geral da página

│   ├── banners/               # Imagens de fundo (Hero)
│   ├── icons/                 # Ícones da interface (SVG)
│   ├── logo/                  # Logotipo da marca
│   └── products/              # Imagens dos produtos

└── README.md                  # Documentação do projeto
```

## 🛠️ Como Executar o Projeto

1. Clone este repositório para sua máquina local.
2. Navegue até a pasta do projeto.
3. Abra o arquivo `index.html` em qualquer navegador moderno.
4. (Opcional) Utilize a extensão **Live Server** no VS Code para visualizar as alterações em tempo real.
